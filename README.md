## Проект по БД

## Цели проекта
+ Получение данных о компаниях и вакансиях с сайта hh.ru, проектирование таблиц в БД PostgreSQL и загрузка полученных данных в созданные таблицы  

+ Получить данные о компаниях и их вакансиях с сайта hh.ru через API.

+ Сохранить данные в базе данных PostgreSQL.

+ Реализовать класс DBManager для работы с данными в базе данных.

+ Обеспечить возможность выполнения различных запросов к данным (например, получение списка вакансий с зарплатой выше средней).

## Используются следующие зависимости:

- poetry init
- json
- pytest
- pytest-cov
- pathlib
- psycopg2
- poetry add --group lint flake8 black mypy isort 



## Использование:
+ Создан абстрактный класс Parser в модуле employerparser.py, дочерний класс EmployerParser, для класса описаны необходимые атрибуты и метод load_employers и метод фильтрации по количеству вакансий
+ Добавлен модуль utils, в котором реализована функция create_database для создания БД
+ Написан модуль dbmanager.py, в котором реализован абстрактый класс DB и дочерний DBManager для подключения к БД и работы с её запросами
+ Есть файлы config.py, setting.py, 
+ Программа запускается через if __name__ == "__main__": в модуле main
