## Проект по БД

+ Получение данных о компаниях и вакансиях с сайта hh.ru, проектирование таблиц в БД PostgreSQL и загрузка полученных данных в созданные таблицы  

## Используются следующие зависимости:

- poetry init
- json
- pytest
- pytest-cov
- pathlib
- psycopg2
- poetry add --group lint flake8 black mypy isort 



## Использование:
+ Создан абстрактный класс Parser в модуле employerparser.py, дочерний класс EmployerParser, для класса описаны необходимые атрибуты и метод load_employers 
+ Добавлен модуль utils, в котором реализована функция create_database для создания БД
+ Написан модуль dbmanager.py, котором реализован абстрактый класс DB и дочерний DBManager для подключения к БД и работы с её запросами
+ Программа запускается через if __name__ == "__main__": в модуле main
    

## Проверка группой линтеров:
* При запуске линтера Flake8 обнаружено 4 ошибки.
* При проверке линтером mypy выводится много ошибок.
* Isort поправил в коде импорты.
